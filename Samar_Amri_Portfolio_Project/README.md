# Samar Amri — Data & BI Portfolio

## Open in VS Code
1. Extract the ZIP.
2. Open the folder `Samar_Amri_Portfolio_Project` in VS Code.
3. Open `index.html`.
4. Recommended: install the VS Code extension **Live Server**.
5. Right-click `index.html` → **Open with Live Server**.

## Add screenshots
Put your images in the `images` folder.

Example:
- `images/cosmochain-dashboard.png`
- `images/ey-dashboard-1.png`
- `images/ey-dashboard-2.png`

In `index.html`, replace a placeholder such as:

```html
<div class="image-placeholder">
  <strong>CosmoChain Screenshot</strong>
  <span>Replace this box with your dashboard image</span>
</div>
```

with:

```html
<img src="images/cosmochain-dashboard.png" alt="CosmoChain Power BI dashboard">
```

## LinkedIn
Search in `index.html` for:

`https://www.linkedin.com/in/your-profile/`

Replace it with your real LinkedIn profile URL.

The CosmoChain LinkedIn video is already linked in the project.

## Main files
- `index.html` → content
- `css/style.css` → design
- `js/main.js` → mobile menu
- `images/` → your screenshots

## EY confidentiality
Only use screenshots that are safe to publish. Remove or anonymize client names, people, emails, IDs, financial values and other non-public information.


## AI / ML screenshots

The portfolio includes dedicated AI/ML areas.

For CosmoChain you can add:
- dosage forecasting / prediction
- damaged-package image detection
- product-validity prediction
- recommendation-system output
- AI assistant interface
- role-based Power BI dashboards

For EY you can add:
- anonymized probabilistic-model output
- anonymized AI assistant interface
- anonymized executive dashboards

Never publish confidential professional data.
